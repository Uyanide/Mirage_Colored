# 全彩幻影坦克生成器

有别于疯狂探寻更优秀的算法，本工具将选择权全部交给你，保证在面对不同的图像素材时均能生成让你最满意的结果。

当然你也可以选择用预设参数一键生成，不过效果并无法得到保证。

可调的参数包括：

- 里图混合权重 (即 1 - 表图混合权重)
- 表图亮度 (色阶缩放)
- 表图去色程度
- 里图亮度 (色阶缩放)
- 里图去色程度

可能的调整思路：

1. 表图越亮，里图越暗，表里分离则越彻底；
2. 里图混合权重更大，则里图质量越高，否则表图质量越高；
3. 去色是表里分离的杀手锏。当无论如何都找不到合适的参数时，可以根据对表里不同的重视程度适当去色。

参数变化的效果展示都是实时的，相信只要素材合适，并不难找到最佳的参数 :)

Enjoy!
